# Retro Games title-screen captures

Lobby and room-list artwork must be actual game captures, not illustrated covers,
recreated logos, or generated images. Use `background-size: contain` so the complete
screen is visible without stretching or cropping.

Added 2026-10-09 from the installed native browser ports:

- `driver2-title-screen.png`: REDRIVER2 opening title screen.
- `sm64-title-screen.png`: Super Mario 64 Mario-head / Press Start screen.
- `sonic1-title-screen.png`, `sonic2-title-screen.png`: RSDKv4 original title scenes.
  The isolated capture session used `[Game] SkipStartMenu=true` to pass the port's
  text launcher; production game settings were not changed.
- `zelda3-title-screen.png`: A Link to the Past opening title, captured from the
  game canvas after the Triforce animation.
- `marioparty-title-screen.png`: original Mario Party title screen, captured from
  the native port at tick 1070 after Start at tick 900 (released at 910).
- `marioparty2-title-screen.png`: original Mario Party 2 title screen, captured
  from the native port at tick 1630 after Start at tick 1000 (released at 1010).

Existing mk64, fzerox, smash64, perfectdark, devilutionx and oot images are also
actual game screens and were retained. No new image-generation tools were used.
